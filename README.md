# Calculator

A simple web-based calculator built with plain HTML and CSS.

## Overview

This project is a clean, stylish calculator UI that allows users to perform basic arithmetic operations in the browser. It is a lightweight static app with no build step or framework dependencies.

## Files

- `calculator.html` — the calculator structure and UI
- `calculator.css` — styling and layout for the calculator

## Features

- Basic arithmetic operations
- Clean modern interface
- Responsive centered layout
- Simple static web app

## Run locally

1. Clone the repository:
   ```bash
   git clone https://github.com/Harper-16/calculator.git
   ```
2. Open `calculator.html` in your browser.

## Example

```text
Open calculator.html in a browser and use the calculator as a standard web calculator.
```

## Notes

This project is intentionally minimal and uses only HTML and CSS, making it easy to customize or extend.
